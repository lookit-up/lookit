# Welcome to LookIt
---

LookIt is a free, feature-packed search tool meant to replace your new tab.

---
## About

- Free
- Customizable
- Ad-less
- Minimal
- AI
- Research
- Image Search
- Movie Search
- Song Search
- Local (doesn't store anywhere but your device)
- Encrypted
- Unlimited

---
## Usage

LookIt is only available as a new tab on [Chrome](https://chrome.com/) as of now.
